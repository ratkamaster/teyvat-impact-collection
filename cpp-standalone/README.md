# Teyvat Arena 3D (Standalone .EXE) ⚔️🔥

Полноценная нативная 3D Action-игра на **C++ и аппаратно ускоренном OpenGL**, скомпилированная в одиночный **`.exe`** файл (без необходимости установки сторонних библиотек или рантаймов!).

---

## 🌟 Особенности игры

1. **Настоящая 3D графика (OpenGL)**:
   - Высокий FPS (60-120+ кадров/сек с `QueryPerformanceCounter` интерполяцией).
   - 3D арена с древними колоннами, пылающими факелами и магическими кругами.
   - Динамическое освещение, тени и частицы в реальном времени.

2. **Боевая система и стихии**:
   - **Левый клик**: Серия быстрых ударов мечом с дуговыми шлейфами (3-ударное комбо).
   - **[E] — Элементальный Навык**: Мощный вращающийся огненный взрыв, поджигающий и отбрасывающий врагов.
   - **[Q] — Взрыв Стихии (Ульта)**: Колоссальный взрыв с тряской экрана и разлётом врагов при 100% энергии.
   - **Инфузия меча стихиями (`1`, `2`, `3`)**:
     - `[1]` — **Пиро 🔥**: Огненный клинок, взрывные оранжевые частицы.
     - `[2]` — **Гидро 💧**: Водный клинок, всплески воды.
     - `[3]` — **Электро ⚡**: Электрический клинок, фиолетовые молнии.

3. **Передвижение и уклонение**:
   - Вид от 3-го лица с плавным вращением камеры вокруг персонажа мышью.
   - **WASD** — Бег относительно взгляда камеры.
   - **Shift / Правый клик** — Быстрый рывок (Dash) с кадрами неуязвимости (i-frames).
   - **Пробел** — Прыжок.
   - Шкала выносливости (Stamina), восстанавливающаяся при ходьбе или отдыхе.

4. **Волны врагов и Эпический Босс**:
   - **Волна 1**: Стихийные Слаймы (прыгают и таранят игрока).
   - **Волна 2**: Каменные Големы с дубинами.
   - **Волна 3 — БОСС**: **Древний Страж Руин (Ruin Titan)**! Огромный механический автоматон со светящимся золотым глазом, ударами по земле и сокрушительной атакой-вертушкой.

5. **Звуковой движок (WinMM)**:
   - Встроенный процедурный синтезатор звуков ударов, рассекания воздуха мечом, взрывов магии и рывка (работает через Windows Multimedia API).

## 🎮 Управление

| Клавиша | Действие |
|---|---|
| **W, A, S, D** | Перемещение персонажа |
| **Мышь** | Свободный обзор 360° |
| **Левый клик** | Атака мечом (комбо из 3 ударов) |
| **Правый клик / Shift** | Рывок / Уклонение |
| **Пробел** | Прыжок |
| **E** | Элементальный навык |
| **Q** | Взрыв стихии (ульта при зарядке) |
| **1, 2, 3** | Переключение стихии меча (Пиро / Гидро / Электро) |
| **Escape / Tab** | Освободить / захватить курсор мыши |
| **R** | Перезапуск игры после победы или поражения |

---

## 🚀 Как запустить

Просто запустите файл **`TeyvatArena.exe`** двойным кликом!
*(Исходный код находится в `src/main.cpp`, сборка через `build.bat`)*.
