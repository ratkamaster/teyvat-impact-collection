# Genshin Impact: Web Edition ⚔️✨

Полноценная 3D Action-RPG в стиле **Genshin Impact**, работающая прямо в браузере без необходимости установки тяжёлых движков.

## 🌟 Особенности игры

1. **Открытый 3D мир**:
   - Зелёные холмы, древние руины Тейвата, водоёмы и деревья.
   - Сундуки с наградами (Обычные, Богатые, Роскошные), открываемые на `[F]`.
   - Парящие Анемокулы, собираемые для получения камней истока.
   - Тотемы стихий и точки телепортации, восстанавливающие здоровье отряда.
   - Воздушные потоки и **планер (крылья)** для полётов по локациям!

2. **Отряд из 4 персонажей (переключение на клавиши `1`, `2`, `3`, `4`)**:
   - **Kaelen (Пиро 🔥)**: Мечник огня. Навык `[E]` — огненный выпад; Взрыв стихии `[Q]` — призыв пылающего феникса.
   - **Marina (Гидро 💧)**: Владелица водной магии. Навык `[E]` — водяной фантом с брызгами; Взрыв стихии `[Q]` — исцеляющий ливень.
   - **Raiko (Электро ⚡)**: Мастер молнии. Навык `[E]` — молниеносный рывок сквозь врагов; Взрыв стихии `[Q]` — небесный шторм молний.
   - **Ventus (Анемо 🍃)**: Владыка ветра. Навык `[E]` — воздушный вихрь, стягивающий врагов и подбрасывающий в воздух; Взрыв стихии `[Q]` — огромный торнадо.

3. **Система элементальных реакций (Elemental Reactions)**:
   - **Пар (Vaporize)**: Пиро + Гидро (умножение урона в 1.5x–2.0x!).
   - **Перегрузка (Overloaded)**: Пиро + Электро (взрыв по площади и отбрасывание врагов).
   - **Заряжен (Electro-Charged)**: Гидро + Электро (периодический урон электричеством).
   - **Рассеивание (Swirl)**: Анемо + Любая стихия (поглощение стихии и раздувание урона по всем окружающим врагам).
   - Цветовая индикация урона в стиле оригинала.

4. **Враги и боссы**:
   - Пиро, Гидро и Электро Слаймы со своими атаками и стихийными аурами.
   - Хиличурлы-воины с дубинами.
   - Мини-босс **Страж Руин (Field Tiller)** с вращающейся атакой, ударами по земле и светящимся ядром!

5. **Система Молитв / Гача (Wish Banner)**:
   - Клавиша `[G]` или кнопка в верхнем меню.
   - Крутки 1x (160 Примогемов) и 10x (1600 Примогемов).
   - Анимация падающей кометы (синяя — 3★, фиолетовая — 4★, золотая — 5★!).
   - Пул легендарных персонажей (Райдэн, Ху Тао, Аяка) и оружия, система гарантов (pity).

6. **Звуковой движок (Web Audio API)**:
   - Процедурные звуки ударов, стихийных взрывов, ветра, воды, электричества, открытия сундуков и золотой молитвы.
   - Фоновая умиротворяющая музыка в стиле Мондштадта.

## 🎮 Управление

| Клавиша / Действие | Функция |
|---|---|
| **W, A, S, D** | Перемещение персонажа |
| **Мышь (клик по экрану)** | Обзор камерой от третьего лица |
| **Левая кнопка мыши** | Комбо обычной атаки (3 удара с элементальным завершением) |
| **Правая кнопка мыши / Shift** | Рывок / Спринт (расходует выносливость) |
| **Пробел** | Прыжок / Раскрыть планер в воздухе |
| **E** | Элементальный навык (Е-шка) |
| **Q** | Взрыв стихии / Ульта (при накоплении энергии) |
| **1, 2, 3, 4** | Быстрое переключение персонажей отряда |
| **F** | Взаимодействие (открыть сундук, активировать телепорт) |
| **G** | Меню Молитв (Гача) |
| **H** | Справка по управлению |

## 🚀 Как запустить

1. Просто дважды кликните по файлу **`start.bat`**
   *ИЛИ*
2. Откройте файл **`index.html`** в любом браузере (Google Chrome, Microsoft Edge, Firefox, Opera и т.д.).
