# ⚔️ Teyvat Impact: Dual Edition Collection (Web 3D & Native C++ .EXE)

Коллекция из двух 3D-игр, вдохновлённых вселенной **Genshin Impact**:
1. **🌐 Web Edition**: Полноценная браузерная 3D Action-RPG на Three.js с открытым миром, отрядом из 4 персонажей, системой элементальных реакций, полётами на планере и гача-баннером Молитв.
2. **⚡ C++ Standalone Edition**: Нативная 3D Action-игра на C++ и аппаратно ускоренном OpenGL, скомпилированная в независимый одиночный `.exe` файл (без внешних зависимостей!).

---

## 🎮 1. Web Edition (`/web-edition`)

Браузерная версия с богатыми механиками оригинального Genshin Impact:
* **Открытый 3D мир**: Холмы, древние руины, сундуки (`[F]`), сбор Анемокулов, точки телепортации.
* **Отряд героев (`1`, `2`, `3`, `4`)**:
  * 🔥 **Kaelen (Пиро)**: Мечник огня. Навык `[E]` — огненный выпад; Ульта `[Q]` — летящий феникс.
  * 💧 **Marina (Гидро)**: Магия воды. Навык `[E]` — водяной фантом; Ульта `[Q]` — исцеляющий ливень.
  * ⚡ **Raiko (Электро)**: Мастер молнии. Навык `[E]` — рывок сквозь врагов; Ульта `[Q]` — небесный шторм.
  * 🍃 **Ventus (Анемо)**: Владыка ветра. Навык `[E]` — взлёт на вихре; Ульта `[Q]` — призыв торнадо.
* **Элементальные реакции**:
  * **Пар (Vaporize)**: Пиро + Гидро (умножение урона в 1.5x–2.0x).
  * **Перегрузка (Overloaded)**: Пиро + Электро (взрыв и отбрасывание).
  * **Заряжен (Electro-Charged)**: Гидро + Электро (периодический ток).
  * **Рассеивание (Swirl)**: Анемо + любой элемент (раздувание стихии по площади).
* **Система Молитв (Гача на клавишу `[G]`)**:
  * Крутки 1x (160 💎) и 10x (1600 💎).
  * Анимация падающей кометы (3★ Синяя, 4★ Фиолетовая, 5★ Золотая!).
  * Пул персонажей (Райдэн, Ху Тао, Аяка) и оружия с системой гарантов.
* **Запуск**: Дважды кликните по `start.bat` или откройте `index.html` в любом браузере!

## ⚡ 2. C++ Standalone Edition (`/cpp-standalone`)

Нативная игра на чистом C++ с прямым выводом через **OpenGL** и Win32 API:
* **Аппаратное 3D ускорение**: Плавные 60-120+ FPS на любом ПК.
* **Боёвка от 3-го лица**:
  * Серия из 3 ударов мечом с цветными дугами атак (ЛКМ).
  * Элементальный Навык `[E]` — круговой огненный вихрь с поджиганием.
  * Взрыв Стихии `[Q]` — мощнейшая ульта при 100% энергии с тряской экрана.
  * Инфузия меча стихиями на клавиши `[1]` (Пиро), `[2]` (Гидро), `[3]` (Электро).
* **3 Волны врагов и Босс**:
  * Слаймы -> Каменные Големы -> **Древний Страж Руин (Ruin Titan)** со светящимся глазом и вертушкой!
* **Встроенный звук**: Процедурный синтезатор через Windows Multimedia API (`winmm.dll`).
* **Запуск**: Просто запустите готовый `TeyvatArena.exe` (116 КБ, не требует установки!).
* **Сборка**: Скрипт `build.bat` (компиляция через MinGW `g++`).
